# junkdrawer

A place for code that doesn't have a home yet: one-off scripts, helpers, half-baked ideas and PoCs. Unorganized and unsupported.

## Convention

Each item gets its own folder, prefixed with the date it was started:

```
2026-10-29-csv-cleanup-script/
2026-11-03-api-client-poc/
```

No other rules. If something grows up, move it to its own repo.
